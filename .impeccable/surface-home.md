# Surface: accueil + partie

Mode: Operate
Primary: `/`
Related: `/salle/[code]`, `/bibliotheque`

Audience: amis en soirée, téléphone ou laptop, prêts à jouer.
Job: entrer dans une salle, poser des fichiers, légender, noter.
Visitor mode: Operate.

## Direction contract

THESIS: La partie est une Polaroid qu’on se passe : un fichier à la fois, légende sur la bande blanche, on retourne pour voir qui a écrit. Refuse le landing Play / cartes de mèmes flottantes / néon de jeu de soirée.

OWN-WORLD: Table basse noyer `#1c1814`, papier instantané `#f6f1e8`, un orange film `#c4a03a` seulement pour l’action. Cadre Polaroid (bords égaux, bande basse épaisse), ombre décalée et floue, une encre. Pas de grille de cartes, pas de chrome de dashboard.

STORY: Le visiteur comprend que le fichier EST le jeu. Il inscrit son nom sur la bande, un code au dos, il entre. Il croit que ses images et GIF suffisent.

FIRST VIEWPORT: Plein écran table. Une Polaroid géante au centre (vide ou un visuel original). Bande blanche : champ prénom. Sous la bande, le code et le bouton Entrer comme une annotation au crayon. Rien d’autre dans le premier regard.

FORM: Polaroids sur la table basse — pick, rang 1 de la liste ancrée, seed `d59a9d30`. Interaction signature : retournement 3D de la Polaroid (auteur révélé). Lumière de phase : lobby = pile sur la table, légende = un tirage, vote = on passe les tirages, score = spread + gommettes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
